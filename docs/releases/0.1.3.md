# Talos CLI 0.1.3

Patch release: ACP `session/delete` for Desktop session list hygiene.

## Changes

- Advertise `sessionCapabilities.delete` in ACP `initialize`.
- Handle `session/delete`: detach an active ACP attachment when present, then persist removal via `runtime.deleteSession`. `session/close` remains detach-only.
- Reject delete on unknown ids and internal sub-agent sessions (same rules as load/resume).

## Validation

- `packages/tui/test/unit/acp-agent.test.ts` (109 tests) including new delete cases.
- Pre-release upstream PR scan: [upstream-pr-watch.md](../upstream-pr-watch.md) — **release: proceed** (2026-10-09), no P0 upstream merge.

## Desktop

Companion GUI can wire a delete control after installing **`@pakiknowledge/tal0s-code@0.1.3`** (or newer). This repository does not ship the Desktop UI.
