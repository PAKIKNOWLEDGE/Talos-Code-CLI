# Talos CLI 0.1.4

Minor release: **`talos studio`** JSON-RPC door with full in-session `TuiRuntime` parity for Desktop (protocol v2).

## Changes

- Add `talos studio` (stdio JSON-RPC, `surface: studio`) on the same CliService as TUI/ACP.
- Studio methods cover session lifecycle, turns, plan/default mode, slash commands, queue, goals, delegation, inspection, feedback, check-in, workspace reads, plugins, and runtime event subscriptions per [studio-parity.md](../studio-parity.md).
- Docs: [studio-protocol.md](../studio-protocol.md), [studio-parity.md](../studio-parity.md), AGENTS/README integration boundary.
- ACP `getTuiAcpSessionControlState` accepts `TuiSessionControlRuntime` (shared with studio).
