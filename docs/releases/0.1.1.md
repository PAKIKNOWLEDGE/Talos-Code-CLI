# Talos CLI 0.1.1

A patch release focused on provider compatibility and transcript clarity.

## Fixes

- Omit an empty tools array when an OpenAI-compatible request has tool-call history but no tool definitions. This fixes a checkpoint/compaction request pattern rejected by some compatible backends; nonempty tool definitions remain unchanged.
- Clear older turn-scoped temporary errors when a new turn starts. Current-turn errors, unrelated local errors, and durable history are retained.
- Display user-authored text literally in the conversation, pending steer messages, and transcript panel. Markdown markers such as underscores and asterisks remain as typed; terminal control sequences are still sanitized.

## Packaging and documentation

- Repository metadata now points to PAKIKNOWLEDGE/Talos-Code-CLI.
- Legal guidance is named LEGAL.md; the MIT license and third-party notices remain unchanged.
- The repository README now focuses on Talos installation and use.

## Scope and validation

This selectively ports upstream PR #199, #388, and only the literal-text portion of #410. The stale-run watchdog, upstream model defaults, and other pending candidates are not included. Model configuration, permissions, data directory, and accepted welcome design are unchanged.

The code change passed six focused files (513 tests) and all 15 existing Windows-applicable verification gates at 953cb94: 5,026 capability tests passed, with 61 existing skips. Release-specific installation results are recorded separately in the release receipt. No paid model request was made. Manual acceptance was waived for this patch. Live gateway acceptance and native NixOS validation were not performed before publication; later NixOS results are recorded in [verification records](../verification.md#native-nixos-verification-2026-10-03).

Talos remains a CLI preview. The desktop GUI and default web search are not included.
